# Changelog

## 0.0.3 - 2026-10-04

- Numerous small visual and UI improvements
- Stream alerts for Free Space, Add Space and Remove Space (temporarily toggled from admin page)
- Free Space cooldown shows on a timer
- Optional sound when a scribe calls a space (disabled by default)
- Uncalling a space now unmarks it on everyone's sheets
- Renaming a space mid-round updates current sheets

## 0.0.2 - 2026-09-13

- New alerts page for OBS that shows when a round starts and when someone calls a bingo
- Free Space now has a cooldown shared by everyone (set from the admin page)
- Add Space only counts towards the round limit once a scribe approves it
- Fixed the "Round is over" message staying on screen after a new round started
